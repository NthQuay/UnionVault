# UnionVault
Wedding Planning Website &amp; App — live at https://unionvault.app

| Path | What it is |
|---|---|
| `index.html` | The whole app (single file, no build step) |
| `sw.js`, `manifest.webmanifest` | PWA service worker and manifest |
| `assets/`, `icons/`, `logos/`, `og-image.png` | Images used by the app and site |
| `supabase/functions/` | Supabase Edge Functions |
| `docs/` | Project reference, changelog, design decisions |
| `docs/sessions/` | Claude Code session handoffs |
| `scripts/` | Helper scripts |
| `CLAUDE.md` | Standing instructions for Claude Code |
