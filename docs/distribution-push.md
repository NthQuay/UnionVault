# Union Vault — Distribution Push (one-time, not content treadmill)

Goal: get in front of couples who are *already* looking for a wedding app — not
make more content. Everything below is copy-paste-ready. No writing left to do,
just submit. Pick off one a day; each takes 10-20 minutes.

Target order (highest intent / lowest effort first):

1. Reddit (today — free, instant, high intent)
2. Product Hunt (one launch day)
3. Directory listings (Easy Weddings, Bride Online, AlternativeTo, SaaSHub, Google Business Profile)
4. Pinterest (reuses existing captions, no new creative)

---

## 1. Reddit — do this first

Reddit is the single highest-intent channel you have access to for zero cost:
people there are *asking* "what app do you use for X", today, constantly.

**Rules to not get banned:** check each sub's rules before posting — most ban
raw self-promo but allow it if disclosed, or allow a dedicated "Self-Promotion
Saturday" thread, or allow it in *replies* to someone asking for a
recommendation. Always disclose you built it. Never post the same comment
across many subs in one sitting (looks like spam) — space it out.

**Subs to check (search "self promo rules" in each sub's sidebar/wiki first):**
`r/AusWeddings`, `r/WeddingPlanning`, `r/BudgetWeddings`, `r/Engaged`,
`r/AustralianWeddings` (if active), plus any wedding Facebook groups you're
already a member of as a guest.

### Template A — replying when someone asks "what app/tool do you use?"
```
I built a free app called Union Vault for exactly this (full disclosure,
I'm the maker, not trying to sneak that past you) — guest list with family
groupings, online RSVPs, seating chart, budget tracker, wishing well with
PayID/bank transfer, and a free wedding website. Built for Australian
weddings specifically (PayID + BSB, not US-style registries).

Free to start, no credit card. unionvault.app — happy to answer questions
if you try it, genuinely want feedback since it's early days.
```

### Template B — a standalone "I built this, AMA" post (only where self-promo is explicitly allowed, or on a Self-Promo day)
```

I'm engaged myself and got frustrated juggling five spreadsheets, so I built
```

### Template C — short version for comment threads (lower-key)
```
Not sure if this helps, but I use/built Union Vault (unionvault.app) — free,
handles guest list + RSVPs + budget + seating + wishing well in one spot.
Built in Australia for Australian weddings specifically.
```

## 2. Product Hunt — one launch day, then done

**Tagline (max 60 chars):**
```
Free wedding planning, built for Australian couples
```

**Gallery description (~260 chars):**
```
Union Vault is a free wedding planning app for Australian couples. Guest
list, online RSVPs, visual seating chart, budget tracker, wishing well with
PayID/BSB, and a free wedding website — all in one place. Free to start,
no credit card.
```

**Topics/tags:** Wedding, Productivity, SaaS, Australia

**Maker's first comment (post immediately after launch, from your own account):**
```
Hey Product Hunt 👋

I'm the maker of Union Vault. I got engaged, opened a spreadsheet for the
guest list, another for the budget, a doc for the timeline — and decided
there had to be a better way, so I built one.

Union Vault is free to start and built specifically for Australian
weddings (PayID/BSB wishing well instead of US-style gift registries,
AUD budgeting, etc). It handles:

- Guest list with family groupings, A/B list, plus-ones
- Online RSVPs with meal choices
- Visual seating chart with conflict detection
- Budget tracker across 12 categories
- Wishing well with PayID + bank transfer tracking
- A free wedding website with custom link + QR code
- Day-of run sheet

Would genuinely love feedback — what's missing, what's confusing, what
you'd want if you're planning (or have planned) a wedding. I'm here all
day to answer questions.
```

**Before launch day:** line up 5-10 people (friends, the test-account
engaged couples you know, anyone) to upvote + comment in the first hour —
Product Hunt's algorithm rewards early velocity.
